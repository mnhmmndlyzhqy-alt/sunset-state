## תפעול ותאימות

פתח `START_GAME.html` מהארכיון המלא עם יתר נכסי המשחק. לצורך השוואה עם שלב 4 (בלי שינוי הקבצים), השתמש בפרמטר `?stage05EntriesOff=1` בשרת HTTP מקומי. כדי להריץ בדיקות CPU מקומיות, נדרש Node.js:

```sh
node QA/run_stage05_of35_acceptance.cjs
STAGE05_ENTRIES_OFF=1 node QA/run_stage05_ab_off.cjs
node QA/run_stage05_stage04_compat.cjs
node QA/run_stage05_smoke_compat.cjs
node QA/run_stage05_physics_compat.cjs
```
