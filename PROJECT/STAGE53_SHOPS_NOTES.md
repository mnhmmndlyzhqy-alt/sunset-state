# חנויות ודמויות בשלב 53

59 החנויות הפעילות קיבלו שלט שם וקטגוריה בעברית, סימון למשקוף ופריטי תצוגה ליד החלון בהתאם לסוג העסק. השלטים מוצמדים למיקום בחזית ומופיעים עד חמישה בו־זמנית בטווח הראייה. ההנחיה ליד הדלת מציגה את שם העסק ואת מקש הכניסה. מסלולי הכניסה, הדלפקים, פריטי הקנייה, הבנק ומזהי השמירה נשארו מקושרים לחנויות המקוריות.

עד שני הולכי רגל מתוך אוכלוסיית העיר הקיימת יכולים לעצור בצד מדרכה ליד חלון, להביט בתצוגה ולהמשיך במסלול. הם נשארים מחוץ לפתח ומפנים את תשומת הלב לשיחה או לסכנה כשהיא מתרחשת.

לדמויות הבנויות במנוע נוספו תווי פנים משתנים, לחיים ועפעפיים מובחנים, לסת תחתונה משוקללת שמגיבה לעוצמת הדיבור, תפרים, רוכסנים ושרוכים. בעמידה חלוקת המשקל משתנה בין הדמויות, ובצעד צדדי הרגליים מתאימות את התנוחה לכיוון התנועה. תלבושות הגיבור מוצגות על השלד המחולל, עם כיפה וציציות בכל תלבושת. השחקנים באצטדיון משתמשים באותו שלד לתלבושות ולתנועות משחק.

אפשר להשתמש בשכבת השלטים באתרים נוספים דרך `Heatline.stage53Shops.registerSign(world, info)`, עם נקודת עיגון, שם, כיתוב משני וכיוון חזית.

## אימות

`node --test QA/stage53_shops.cjs` בודק את גאומטריית השלטים, מרווח הכניסה, פתיחה ויציאה מכל 59 החנויות, שמירה בבנק, תגובת הולך רגל, תקינות משקלי השלד והפעלת הלסת והתלבושות. הבדיקה משתמשת במשחק ובמפה האמיתיים עם תצוגה מדומה. איכות תמונה, קריאות במסך בפועל וקצב פריימים דורשים מדידה בדפדפן.
