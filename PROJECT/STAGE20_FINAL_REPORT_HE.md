# SUNSET STATE CITY20 — חבילת מסירה שלבים 1–20

החבילה מכילה את המשחק המקורי 4.7.9 ואת כל התוספות המצטברות, כולל 130 מבנים ממופים, שיפורי שטח, כבישים, מים, בניינים, חזיתות, חללי מבואה, צמחייה, חיות ותאורת צהריים בהירה כברירת מחדל.

## פתיחה
1. חלץ את כל הקבצים מתיקיית ה-ZIP.
2. פתח START_GAME.html ב-Chrome או Edge. אם מדיניות הקבצים המקומיים חוסמת טעינה, הפעל שרת HTTP מקומי בתיקייה.
3. לחץ Play. WASD לתנועה; F3 לאבחון FPS ורזולוציה; F4 למצבי איכות.
4. להפעלת מחזור יום ולילה השתמש בכפתור ▶ של השעון; ברירת המחדל היא 12:15, מחזור כבוי.
5. בדיקות ביצועים: פתח START_GAME.html?city20qa=1, הרץ כל אחת משש הסצנות ושמור JSON.

## מגבלות בדיקה
- בדיקות קוד ותקינות ארכיון אינן מחליפות בדיקות חזותיות או משחק בפועל.
- לא בוצע אימות אמיתי של 1920×1080 עם 50FPS על GPU של המשתמש.
- מדידת requestAnimationFrame היא מדידת קצב הצגה, לא פרופיילר GPU.
- חלק מהשיפורים הם פרוצדורליים/דקורטיביים ואינם נכסי AAA פוטוריאליסטיים מלאים.
