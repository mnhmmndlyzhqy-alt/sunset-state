# SUNSET STATE · גרסה 54 — טרמינל חי והאי שלך

**זו הגרסה המלאה והעדכנית.** ההוראות המפורטות, השליטה במטוסים והגדרות הרזולוציה נמצאות ב־[README_STAGE54_HE.md](README_STAGE54_HE.md).

בעדכון 54 נוסף טרמינל עם כניסות, נוסעים, צ׳ק־אין, בידוק, שערים, כבודה ובית קפה. נוספו לוח טיסות והכוונה, ותוקנו בעיות שמירה ושיחות.

כל השדרוגים הקודמים כלולים: אי גדול בבעלותך עם שש דירות שאפשר לבנות בהדרגה, משא ומתן עם דיירים, שכירות ותחזוקה. אפשר להביא אליו רכבים, מטוסים וסירות ולאחסן אותם. נוספו תחבורה בין האיים, אצטדיון פעיל, חנויות ברורות, דמויות מפורטות ותיקוני כבישים. שדרוגי המצלמה, הנהיגה, הדיבוב, הבתים והרזולוציה מהגרסאות הקודמות כלולים.

## הפעלה ב־Windows

חלץ את כל קובץ ה־ZIP, פתח את תיקיית `SUNSET_STATE` והפעל את `RUN_GAME_WINDOWS.bat`. הקובץ מפעיל שרת מקומי עם Python 3 או Node.js ופותח את המשחק בדפדפן. אפשר לסגור את חלון השרת בסיום המשחק.

אפשר גם להפעיל מהתיקייה `python -m http.server 8765 --bind 127.0.0.1` ולפתוח בדפדפן את `http://127.0.0.1:8765/`. פתיחת קובץ ה־HTML ישירות עלולה למנוע טעינה של שיחות ונכסים.

## מערכות העיר הכלולות גם בגרסה זו

- מצלמת מרדף ומצלמה רחבה מתאימות את המסגור למהירות ולגודל הרכב. המצלמה נסוגה ליד קירות ומתרחקת בהדרגה כשהדרך מתפנה.
- כניסות מוארות, חומרי גימור שונים בלובי לפי סוג הבניין, ותצוגות שאפשר לגלות בבניינים. סימן זהוב ליד תצוגה מוביל לחותמת ביקור.
- המעלית זוכרת באיזו קומה נמצא התא. אפשר להזמין אותה, לראות את זמן ההגעה, לבחור יעד ולהוסיף תחנות בזמן הנסיעה. ביציאה מהתא התור מתנקה.
- תושבים מגיבים להתקרבות של רכב ולבלאגן בסביבה. שיחה נעצרת כשהאזרח נבהל או כשהשחקן מתרחק. דיבור סביבתי מקבל כתוביות, גם כשהקול מושתק.
- אזעקה ותגובה משטרתית מחודשות בבנק, משחק זיכרון בכספת והתנהגות שונה לניידת מיירטת ולניידת שעוקבת אחר מיקום אחרון ידוע.
- המעבר בין שחייה לצלילה הדרגתי יותר. האור נשבר על הקרקעית, הקצף נשבר בגלים ליד החוף, ושחיינים משאירים שובל. רכבי שטח וסטיישן קיבלו גגונים, ומכוניות ספורט קיבלו ספוילרים.
- ביומן המשימות נוספו מרוץ נגד השעון, משימת צלילה ומשלוח ערב. המסך הראשי והממשק אורגנו מחדש, וליומן נוספו מסננים.

## שמירות

ניהול האי ואחסון כלי התחבורה שומרים אוטומטית את ההתקדמות, הכסף והחוזים יחד. כפתור ״המשך משמירת האי״ טוען את השמירה האוטומטית. אפשר גם לבחור אחת משלוש המשבצות וללחוץ ״שמור״ בתפריט ההשהיה, לייצא ולייבא קובץ שמירה. השמירות המקומיות זמינות באותה כתובת ובאותו דפדפן.
