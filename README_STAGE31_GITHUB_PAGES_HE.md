# SUNSET STATE שלב 31 — חבילת דפדפן

1. חלץ את כל תכולת ZIP האתר לאותה תיקייה. פתח שרת מקומי מתוך התיקייה (`python -m http.server 8000`).
2. פתח `http://localhost:8000/index.html` וחכה לטעינת המשחק וכל הנכסים.
3. נהג ברכב יבש ורטוב, בדוק בלימה רגילה לעומת בלם יד, ודא שאין סטייה מלאכותית בהגה ברכב בריא.
4. פגע בעדינות במרכב ובגלגל, עקוב אחר השינוי בהיגוי, תקן במוסך ובדוק חזרה להיגוי תקין.
5. עבור מאחורי תנועת אזרחים ואוטובוס, כולל במחלף דו־מפלסי, ובדוק שהרכב בולם בלי להסתחרר ובלי בלימות שווא.
6. בדוק את ששת דגמי INTERCEPTOR, הניידת והמונית ואת פנסי המשטרה/הנהיגה.
7. השווה עם `?stage31VehiclesOff=1` והחזר למצב רגיל.
8. מדוד 1920×1080 ו־50FPS לפחות על GPU חומרתי ונסה 10 דקות משחק; **לא בוצע בסביבה זו**.
9. להעלאה ל־GitHub Pages העלה קבצים מחולצים ולא את ZIP. אמת את הקישור הציבורי.

החבילה המקומית אינה קישור ציבורי פעיל.
