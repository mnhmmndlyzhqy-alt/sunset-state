# SUNSET STATE — שלב 30 / חבילת אתר סטטי

1. חילוץ כל הקבצים לתיקייה אחת. `index.html`, `assets/`, `QA/` ו-`.nojekyll` בשורש.
2. הפעלה מקומית: `python -m http.server 8000` ולפתוח `http://localhost:8000/`.
3. בדוק בשחקן, 4 NPC מקרוב, סיבוב ראש, הליכה/ריצה/קפיצה, שיחה/טלפון, תיירים, כניסה/יציאה מרכב ושחייה. ודא שזווית הנעל/פנים אינה חודרת לגאומטריה.
4. A/B בעזרת הוספת `?stage30CharactersOff=1` לכתובת; ההבדל חייב להיעלם ללא שינוי במערכות המשחק.
5. בדוק 50FPS ב-1920×1080 על כרטיס מסך אמיתי, כולל בסביבת עומס. **היעד לא אומת בגרסה המקומית**.
6. להעלאה: העלה תוכן תיקייה זו לשורש מאגר GitHub Pages, לא את קובץ ה-ZIP עצמו. אמת שאין קובצי JS/נכסים חסרים.

**האתר לא פורסם מרחוק ואיננו טוענים שיש כתובת ציבורית פעילה.**
