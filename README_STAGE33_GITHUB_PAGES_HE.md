# הפעלה ופרסום — SUNSET STATE שלב 33

1. חלץ את קובץ `SUNSET_STATE_STAGE33_GITHUB_PAGES_SITE.zip` לתיקייה אחת.
2. הרץ באותה תיקייה `python -m http.server 8000` ופתח `http://localhost:8000/index.html`.
3. אם צריך לפרסם, העלה את כל הקבצים והתיקיות לשורש מאגר GitHub Pages ואפשר פרסום מן הענף המתאים. הקובץ `.nojekyll` חיוני למניעת שיבוש נתיבי נכסים.
4. בדוק במשחק חי: משימות אזרחיות (שיחה/מרקחת/גינה, קפה/גלריה/צילום, מאפייה/אוטובוס/כיכר), תגמולים חד פעמיים, מסך משימות, הוצאות/הכנסות, מניעת דריסת הולכי רגל, מרדפים, שמירה וטעינה.
5. בדוק A/B עם `?stage33CityOff=1` ולאחר מכן רענון, ובדוק שוב FPS ב־1920×1080 (יעד 50FPS ומעלה).

**לא בוצעה פריסה ציבורית בידי הבונה.** בדיקות Node מקומיות אינן ראיה לעמידה ביעד GPU.
