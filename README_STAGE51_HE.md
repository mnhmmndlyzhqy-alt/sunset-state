# SUNSET STATE — Stage 51: נהיגה וטיסה

גרסה זו ממשיכה את `SUNSET_STATE_CITY_UPDATE.zip` שסופק. היא כוללת את המשחק המלא, עם המפה, התוכן וקובצי הקול הקיימים, ותיקונים למצלמה, לנהיגה, לטיסה ולדיבוב.

## הפעלה ב־Windows

1. חלץ את קובץ ה־ZIP לתיקייה רגילה.
2. היכנס לתיקיית `SUNSET_STATE` והפעל `RUN_GAME_WINDOWS.bat`.
3. השאר את חלון השרת פתוח בזמן המשחק. הדפדפן אמור להיפתח בכתובת `http://127.0.0.1:8765/?build=51`.
4. לחץ על כפתור ההתחלה במשחק. הפעולה הזו מאפשרת לדפדפן להפעיל גם את השמע.

קובץ ההפעלה משתמש ב־Python 3 או ב־Node.js אם אחד מהם מותקן. הוא אינו מתקין תוכנות בעצמו. אם אף אחד מהם אינו זמין, הוא מציג הודעה במקום לפתוח משחק שחלק מהשיחות שלו לא יוכלו להיטען.

אפשר להפעיל ידנית מתוך תיקיית המשחק:

```sh
node TOOLS/serve_game.cjs 8765
```

או:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

לאחר מכן פתח את הכתובת שלעיל. הפעלה בלחיצה כפולה על `index.html` עלולה לחסום את טעינת קובצי הדיבוב ומודולי הדיבור; המשחק מציג על כך הודעה אם הוא נפתח בדרך זו.

אם נפתחת גרסה ישנה, סגור את חלון השרת של הגרסה הישנה והפעל את הקובץ מחדש. השתמש באותו דפדפן ובאותה כתובת שבהם שמרת קודם. שמירות דפדפן משויכות גם לכתובת, ולכן `localhost` ו־`127.0.0.1` אינם חולקים אותן. אפשר להשתמש ביצוא וביבוא השמירות הקיימים כדי להעביר התקדמות בין כתובות או דפדפנים.

## מה השתנה

### מצלמת הדמות והרכב

ההליכה והנהיגה משתמשות כעת באותה התנהגות של מצלמת מעקב: גרירה לסיבוב ולהגבהת המבט, תנועה חלקה וחזרה פנימה ליד קירות. מרחק המצלמה מותאם לגודל הדמות או הרכב. נשמרו המצלמות המיוחדות של מבנים, תחבורה ציבורית, שחייה וטיסה.

- גרירת עכבר מסובבת את המצלמה. כשהדמות מחזיקה כלי, השתמש בגרירה בלחצן הימני; הפעולה בלחצן השמאלי נשמרת.
- `C` מחליף מבט.
- החזק `B` למבט לאחור בהליכה, או `Q` בנהיגה.

### פניות חדות יותר ברכב

ההיגוי מגיב מהר יותר, זווית ההיגוי גדולה יותר במהירויות עירוניות, והרכב נכנס לפנייה באופן החלטי יותר. התוספת מתמתנת בהדרגה במהירות גבוהה. בלם היד, נזק לרכב, אחיזת הכביש וההשפעה של גשם נשארו במערכת.

### מודלים מפורטים כברירת מחדל

המצב הרגיל שומר על הגרסאות המפורטות של המודלים הקיימים לאורך טווח התצוגה שלהם. הוסרו ההחלפות המוקדמות לגרסאות פשוטות של דמויות, מכוניות, תחבורה ובעלי חיים, וכן מגבלות שגרמו לחלק מהקהל לקבל מודל פשוט יותר. זו בחירה בגרסאות המפורטות שכבר כלולות במשחק.

עצמים רחוקים מאוד או מחוץ לשדה הראייה עדיין אינם מצוירים. מודל חיצוני עשוי להציג זמנית את דגם הגיבוי בזמן טעינת הגאומטריה והמרקמים שלו. טעינה כזו שונה מהחלפת מודל בגלל מרחק.

`F4` שולט במצב רזולוציית הציור, בנפרד מאיכות המודלים. רק אם תבחר במפורש להוסיף לכתובת `&adaptiveQuality=1`, יופעל שוב מצב איכות המודלים המותאמת למרחק. מצב זה אינו ברירת המחדל.

### דיבוב ושיחות

הפעלת השמע הועברה לפעולת המשתמש, טעינת מערכת הדיבור יכולה להתאושש מכשל זמני, וקובץ הקלטה חסר או תקול מקבל גיבוי באמצעות מנגנון הסינתזה העברי המקומי. עצירה, התחלה מחדש, השתקה או מעבר ללשונית אחרת מפסיקים שיחות פעילות ושיחות שממתינות לטעינה.

בתפריט העצירה נוסף מחוון לעוצמת דיבור התושבים, והבחירה נשמרת. כפתור ההשתקה הכללי עדיין משתיק את המשחק. שיחות זוכרות את השם שהוצג ואת המקום האחרון שנדון במהלך הריצה הנוכחית, ובקשות חוזרות יכולות לקבל תשובות שונות מהמאגר הקיים. השיחות עובדות מקומית באמצעות כללים ומאגר ההקלטות, ללא שירות ענן חדש.

### תנועת העיר

רכבי העיר בולמים מראש מול רכב או אוטובוס שחוצה מימין במסלול התנגשות צפוי. הבדיקה מתחשבת בכיוון, בתנועה ובמפלס הדרך. גם בדיקת מעבר החצייה משתמשת בהפרדה בין מפלסים, כדי שרכב על גשר לא יחסום מעבר מתחתיו.

## איך מטיסים

1. פתח את המפה ובחר **שדה תעופה · טיסה עצמאית** כיעד.
2. גש לסימון הטיסה מחוץ לטרמינל. כשמופיעה האפשרות, לחץ `E` כדי לעלות למטוס **SKYLINE 320** שבתחילת המסלול.
3. החזק `W` כדי להעלות מצערת ולהאיץ לאורך המסלול. המצערת שומרת על הערך שלה כשמשחררים את המקש.
4. לקראת כ־126 קמ״ש ומעלה, החזק `Shift` או חץ למעלה להרמת האף. לאחר ההמראה שחרר את מקש ההרמה כדי להתיישר.
5. הפנה את המטוס בעזרת `A` ו־`D` או החצים לצדדים. הורד את האף עם `Ctrl` או חץ למטה.

| מקש | פעולה בטיסה |
|---|---|
| `W` / `S` | הגדלה / הקטנה של המצערת |
| `A` / `D`, או חצים לצדדים | פנייה והטיה |
| `Shift`, או חץ למעלה | הרמת האף וטיפוס |
| `Ctrl`, או חץ למטה | הורדת האף והנמכה |
| רווח | בלימה על הקרקע |
| `C` | מעבר בין מצלמת טיסה קרובה ורחבה |
| `E` | כניסה; יציאה רק אחרי נחיתה ועצירה מלאה |
| `R` | החזרת המטוס לנקודת ההמראה |

לנחיתה, התיישר עם המסלול, הקטן מצערת והנמך בהדרגה. שאף לגישה מתונה סביב 140–200 קמ״ש, עם כנפיים מאוזנות. גלגלי הנחיתה נפתחים אוטומטית. לאחר המגע במסלול החזק רווח לבלימה; צא עם `E` רק לאחר עצירה מלאה. לוח הטיסה מציג מהירות, גובה, מצערת, מצב גלגלים ושלב טיסה.

הטיסה מיועדת למשחק ארקייד. פגיעה במכשול, יציאה מגבול המפה או נחיתה שאינה בטוחה מחזירות את המטוס למסלול עם הסבר. מסך מגע כולל גם כפתור להנמכה. ליד דלת המטוס אפשר לעלות שוב לאחר יציאה.

## שמירות והתקדמות

פורמט השמירה הקיים נשמר. שמירה בזמן טיסה שומרת את ההתקדמות, אבל מיקום הטיסה עצמו זמני: בטעינת השמירה הדמות חוזרת ברגל לנקודה שבה עלתה למטוס. כך טעינה אינה משאירה את השחקן באוויר ללא כלי טיס פעיל.

`F5` מבצע שמירה ידנית במשבצת שנבחרה. אפשרויות שמירה, טעינה, יצוא ויבוא נשארו בתפריט העצירה.

## בדיקות ומגבלות אימות

תוצאות האימות מפורטות ב־`QA/STAGE51_VALIDATION_REPORT_HE.md`. בדיקות המשחק מפעילות את קוד המשחק, העולם, הפיזיקה והשמירות בפועל, אך מחקות את ממשק הדפדפן ואת התקני הציור והשמע. הן אינן צילום או בדיקת משחק ידנית.

בסביבת העבודה לא התאפשרה פתיחת המשחק בדפדפן חי. לכן המראה בפועל, האזנה לדיבוב וקצב הפריימים על Intel UHD 730 עדיין צריכים להיבדק במחשב המשחק. אין כאן הבטחה לביצועי 50 FPS ברזולוציית Full HD. שמירת מודלים מפורטים מגדילה את עומס הציור בהשוואה לגרסאות הפשוטות.

קובץ המקור נשמר בנפרד ולא נדרס. החבילה הזו היא גרסה חדשה ומלאה.
