# SUNSET STATE — חבילת GitHub Pages שלב 28

החבילה מכילה את אתר המשחק המלא, `index.html`, `START_GAME.html`, קובצי JS, נכסים ו־`.nojekyll`. זו אותה גרסת קוד כארכיון המקור המצטבר, שנארזה כאתר סטטי.

לבדיקה מקומית: חילוץ ZIP לתיקייה, הרץ בתוכה `python -m http.server 8000` ופתח `http://localhost:8000/index.html`. לפרסום: העלה את **תוכן** התיקייה לשורש מאגר GitHub Pages, והפעל Pages בענף המתאים. אסור לטעון שפורסם URL חי לפני אימות בפועל.

לבדיקת תאימות מול שלב 27: הוסף `?stage28FacadesOff=1` לכתובת.

**חשוב:** דרוש מחשב עם GPU ו־WebGL2 לאימות FPS ואיכות הגרפיקה. אין אימות 1080p/50FPS בסביבת ההרצה הזאת.
