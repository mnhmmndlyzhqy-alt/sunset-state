# SUNSET STATE — גרסה 52: העיר, הבתים והטיסה

גרסה מלאה ומצטברת של המשחק, המבוססת על `SUNSET_STATE_CITY_UPDATE.zip` ועל השדרוג הקודם, גרסה 51. קובצי המודלים, הטקסטורות והקול המקוריים כלולים בארכיון. אין צורך להוריד אותם בנפרד.

## הפעלה

1. חלץ את כל קובץ ה־ZIP לתיקייה חדשה.
2. פתח את תיקיית `SUNSET_STATE` והפעל את `RUN_GAME_WINDOWS.bat`.
3. השאר את חלון השרת פתוח בזמן המשחק. הכתובת היא `http://127.0.0.1:8765/?build=52`.
4. אם גרסה קודמת כבר רצה, סגור את חלון השרת הישן לפני הפעלת הגרסה החדשה. במקרה של קבצים ישנים במטמון, רענן עם `Ctrl+F5`.

המפעיל משתמש ב־Python 3 או ב־Node.js, לפי מה שמותקן במחשב. אפשר גם להריץ מתוך תיקיית המשחק:

```bash
node TOOLS/serve_game.cjs 8765
```

או:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

לאחר מכן פתח את הכתובת שלמעלה. פתיחת HTML ישירות מהקבצים אינה מספיקה לטעינה אמינה של מודולי השיחות וקובצי הדיבוב.

## כניסות ובניינים

- הגישה לכניסה נבדקת ביחס לכיוון הדלת ולמעבר הפנוי. אפשר לעבור ברגל או ללחוץ **E** מול הדלת.
- פרטי הכניסה והלובי כוללים מסגרות, תאורת פתח וחומרי גימור התואמים לסוג המבנה.
- דלפקי הקבלה בחמישה מבנים קטנים הוזזו לצד המעבר יחד עם גופי ההתנגשות שלהם.
- יציאה מודרכת בודקת שהנתיב נשאר פנוי. חסימה שמופיעה במהלך היציאה עוצרת את המעבר במקום להוליך את הדמות לתוכה.
- בקרת המעלית מציגה רק יעדים זמינים. בניינים בני קומה אחת אינם מציעים מעלית, ויעד גג מופיע רק כאשר יש חיבור לגג.
- גובה חללי הפנים של מבני CITY20 מותאם ליסודות הקיימים. אותו גובה משמש את הדמות, המעלית, המדרגות, התאורה וטעינת השמירה.

## בתים פרטיים

בקתות, וילות ואחוזות שנבנות דרך מערכת הנכסים הקיימת כוללות כעת קומת קרקע שאפשר להיכנס אליה ברגל. נוספו דלתות הזזה, פתחים וחלונות, רצפה וגישה המותאמות לקרקע, ריהוט, תאורה פנימית וחצר לפי סוג הבית. לקירות ולרהיטים יש גופי התנגשות, והמצלמה נשארת בתוך גבולות החדר כשנכנסים אליו.

קומת הקרקע נגישה למשחק. הקומות העליונות בווילות ובאחוזות משמשות לפרטי המבנה החיצוני. הבעלות, הרכישה, ההשכרה וסוגי הנכסים ממשיכים להשתמש במערכת הקיימת. שמירה רגלית מתוך בית שומרת את מיקום הדמות.

## מטוסים

אפשר לגשת לדלת של אחד מחמשת מטוסי SKYLINE 320 החונים בשדה התעופה וללחוץ **E**. סימון הטיסה ליד הטרמינל נשאר זמין לעלייה והתחלה על המסלול.

| מקש | פעולה |
| --- | --- |
| **W / S** | הגדלה או הקטנה של המצערת |
| **A / D** או **← / →** | היגוי על הקרקע והטיה בטיסה |
| **Shift / ↑** | הרמת האף |
| **Ctrl / ↓** | הורדת האף והנמכה |
| **T** | הגבלת מהירות להסעה על הקרקע |
| **X** | מעבר למצב תנועה לאחור כשהמטוס עצר; **W** לתנועה ו־**רווח** לעצירה |
| **רווח** | בלימה על הקרקע |
| **C** | החלפה בין מבט מרדף קרוב, רחב ומבט קדמי מהאף |
| **L** | הצגת עזרי נחיתה וכיוון המסלול |
| **E** | יציאה לאחר נחיתה ועצירה מלאה |
| **R** | החזרת המטוס לנקודת המראה פנויה |

מטוס חונה מתחיל במצב הסעה איטית. לאחר יישור על המסלול, האצה והרמת האף מאפשרות המראה. אפשר לכבות את מגביל ההסעה גם באמצעות **T**. במצב תנועה לאחור, עצור ואז לחץ **X** שוב לפני תחילת ההמראה.

עזר הנחיתה מציג מרחק לסף המסלול, סטייה מקו האמצע, תיקון כיוון ומידע על מהירות והנמכה. סימונים קרובים למסלול עוזרים לזהות את הכיוון שנבחר. העזר אינו מטיס את המטוס בעצמו. לאחר שינוי כיוון הטיסה, כיבוי והפעלה מחדש עם **L** בוחרים את כיוון המסלול הקרוב לכיוון החדש.

נוספו בלימה לקראת קצה המסלול, עצירה מול מכשול בהסעה ותאורת נחיתה כשהגלגלים למטה. התאורה והעצמים הקרובים בטיסה נבחרים סביב המטוס. המבט הקדמי ממוקם לפני האף של המודל; הוא אינו תא טייס מרוהט.

המטוס נשאר במקום שבו עצרת ויצאת ממנו במהלך המשחק. טעינת שמירה או התחלה מחדש מחזירות את מטוסי החניה לעמדות המקוריות. שמירה בזמן טיסה שומרת את ההתקדמות, וטעינתה מחזירה את הדמות לנקודת העלייה הקרקעית.

## גרפיקה, רזולוציה ו־FPS

פתח את תפריט ההשהיה באמצעות **Esc**. באזור ״גרפיקה וביצועים״ אפשר לבחור:

| מצב | מה הוא עושה |
| --- | --- |
| **1080p** | ברירת המחדל. מבקש Full HD תוך שמירה על יחס המסך ובכפוף למגבלות המכשיר. |
| **רזולוציית המסך** | משתמש בגודל אזור המשחק ובצפיפות הפיקסלים של הדפדפן. |
| **1440p** | מבקש QHD, בכפוף למגבלות המכשיר. |
| **קנה מידה אישי** | מאפשר 50%–150% מרזולוציית המסך. |
| **התאמה לקצב הפריימים** | משנה את הרזולוציה הפנימית בטווח 65%–100% לפי מדידות בזמן המשחק. |

**F4** מחליף בין המצב הקבוע האחרון להתאמה אוטומטית. אפשר לקבוע יעד של 30–120 FPS למצב האוטומטי; ברירת המחדל היא 50. זהו יעד עבודה, ולא התחייבות לקצב שיתקבל. המערכת מחכה למדידה ממושכת, ומבטלת הפחתת רזולוציה שלא שיפרה את זמן הפריים.

הממשק מציג בנפרד את הרזולוציה הפנימית ואת גודל הפלט, ורק לאחר שנאספו פריימים מציג את קצב הפריימים שנמדד במשחק. הגדרות התצוגה נשמרות בדפדפן.

איכות המודלים נשארת מפורטת כברירת מחדל. מצב הרזולוציה האוטומטי אינו מחליף דמויות או רכבים במודלים הפשוטים. לצורך השוואות טכניות בלבד, אפשר עדיין להפעיל את בחירת המודלים ההיסטורית עם `?adaptiveQuality=1`.

### מה שופר בעבודת המנוע

- נתוני המודלים הנעים נאספים להעלאה משותפת לכל מעבר ציור, במקום להעלות כל קבוצת צורות בנפרד.
- חלק מהגדרות הציור נשמרות לשימוש חוזר בין פריימים.
- אנימציית השלד משתמשת מחדש במערכי עבודה, כדי להפחית הקצאות זיכרון חוזרות.
- תמונה שמוצגת בגודל שבו צוירה אינה עוברת שחזור הגדלה מיותר. הגדלה עדיין משתמשת בשחזור מתאים, והחידוד מוגבל כדי לצמצם שוליים בהירים או כהים.
- התנועה והולכי הרגל משתמשים בחיפוש מרחבי מקומי. כללי ההתנגשות והפחד המקוריים עדיין מחליטים על התוצאה, באותו סדר שחקנים.
- בדיקות גובה מול אוטובוסים ורכבות מתבצעות רק לאחר בדיקת הקרבה הפשוטה.

## שמירות ותאימות

בחר משבצת שמירה בתפריט ההשהיה. אפשר לייצא את השמירה לקובץ ולייבא אותה דרך הממשק הקיים. כדי להמשיך מאותה שמירה מקומית, השתמש באותו דפדפן ובאותה כתובת `127.0.0.1:8765`. `localhost`, כתובת של אתר אחר ופרופיל דפדפן אחר משתמשים באחסון נפרד.

העדכון שומר על פורמט השמירות הקיים. קובצי התוכן המקוריים לא הוסרו. לא בוצעה העלאה לאתר או שינוי של אתר מתפרסם.
