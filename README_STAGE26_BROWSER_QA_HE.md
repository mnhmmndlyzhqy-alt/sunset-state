# שלב 26/35 — בדיקת ראיות חזותית במשחק עצמו

מטרת הכלי: לתעד תוצאות בפועל של 25 הממצאים המקוריים. **51 בדיקות CPU אינן 25 בדיקות משחק אנושיות.** עדיין לא קיים אישור 50FPS ב־1920×1080.

## הפעלה
1. חלץ את חבילת האתר או את החבילה המלאה.
2. ב־Windows הפעל `RUN_STAGE26_BROWSER_QA_WINDOWS.bat` לאחר התקנת Python, או פתח שרת HTTP מקומי בתיקייה הראשית.
3. פתח `http://127.0.0.1:8765/index.html?stage26qa=1`.
4. הפעל את המשחק והשתמש בחלונית למעלה מימין. בחר ממצא לפי מזהה המקור, בצע את התרחיש וקרא את תנאי ההצלחה המקורי.
5. בחר ״עבר״ רק אם ראית אותו במשחק. במקרה כשל, רשום מיקום, אופן שחזור ושעה; צרף צילום באמצעות ״צילום פריים אמיתי״. אם הצילום ריק, השתמש בצילום המסך המובנה של הדפדפן.
6. לחץ ״ייצוא JSON״ ושמור את `SUNSET_STAGE26_BROWSER_EVIDENCE.json` יחד עם צילומי PNG. קובץ זה אינו נכלל מראש בארכיון: הוא חייב להיווצר במחשב שבו מריצים את המשחק.
7. במידת האפשר, הרץ גם `?stage22qa=1` ו־`?stage23qa=1` בנפרד עבור GPU וקריאות ציור. מדידת 50FPS דורשת 6 סצנות, 1920×1080 ומזהה חומרה מתאים.

## קווי בסיס למדידה
- 52 כבישים, 429 רישומי כניסות, 214 פעילות, 59 חנויות עם חלל פנים.
- 166 אדניות, 28 פנסי רחוב שנבדקו, 360 גופי התנגשות לריהוט רחוב.
- 1,586 חלונות צד/אחור, מהם 864 חוברו לזכוכית שבירה.
- 8 תנינים, מערכת שמירות של 3 משבצות ידניות ושמירה אוטומטית.

## מה נחשב ראיה ומה לא
- צילום PNG שנוצר מהקנבס של הרינדור בזמן `renderer.draw` הוא ניסיון צילום מהמשחק האמיתי, לא תמונה מלאכותית. בדוק בעין שאינו שחור/ריק ושאפשר לזהות בו מיקום ורלוונטיות.
- נתוני JSON הם תצפית ממנוע המשחק ורישום ידני של הבודק; סימון PASS הוא **דיווח משתמש** ולא הוכחה אוטומטית.
- מבחן CPU עם רינדור מדומה מוכיח שקוד ופיזיקה פעלו בבדיקה הזאת, לא שהמשחק נראה טוב או פועל ב־50FPS.
- האתר מוכן להעלאה; לא בוצעה העלאה לחשבון GitHub ולא נוצרה כתובת ציבורית חדשה.

## בדיקות שחייבות להישאר פתוחות עד ביצוע אמיתי
- נסיעה ארוכה ללא חדירה דרך מחסומים, כולל גשרים/מנהרות/שיפועים.
- רינדור תאורת פנים, שבירת חלונות, חלופות LOD לתנינים ומעברי מצלמה.
- ניווט NPC במשך 10 דקות משחק אמיתי עם תנועה, הולכי רגל ורכבים.
- שמירה/טעינה אחרי סגירת דפדפן ולא רק בסימולציית Node.
- ריצת 1080p אמיתית ומדידת 50FPS עם GPU חומרתי ולא Software Rasterizer.
