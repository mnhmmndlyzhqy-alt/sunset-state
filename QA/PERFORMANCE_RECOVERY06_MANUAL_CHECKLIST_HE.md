# מדידה בשטח — חלק 6, למשתמש

- [ ] המשחק נפתח ומגיב למקשי WASD וקפיצה.
- [ ] F3 מציג 1920x1080 אמיתיים ב-WebGL2 (אם נתמך בחומרה).
- [ ] F10 מייצא דוח ביצועים; בצע זאת אחרי חימום של 3 דקות.
- [ ] בדוק 3 דקות הליכה + 3 דקות נהיגה + 3 דקות תנועה עירונית עם הרבה אזרחים.
- [ ] בדוק חציית גשר ורכבים במפלסים שונים.
- [ ] בדוק את הגרפיקה של התנינים מרחוק ומקרוב ואת המעבר בין המודלים.
- [ ] בדוק 60 שניות בלובי ו-60 שניות מול אזור חוף.
- [ ] הפעל וכבה מחזור יום/לילה ובדוק בהירות תחילת משחק.
- [ ] קבל השוואה נוספת מאותו מקום עם ?performanceRecovery6Off=1.
- [ ] בדוק קצב ממוצע והאטות ותקיעות חריגות (stutter), לא רק מספר FPS רגעי.
