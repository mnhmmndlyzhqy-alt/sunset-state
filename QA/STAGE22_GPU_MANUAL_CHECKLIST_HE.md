# בדיקת ביצועים אמיתית — SUNSET STATE שלב 22

**היעד:** 1920×1080 ברינדור פנימי מקורי, לפחות 50FPS ב־6 סצנות, ללא הסתמכות על נתוני CPU בלבד.

## כיצד לפתוח את הבדיקה ב־Windows

1. חלץ את כל קובצי ה־ZIP, לא רק את קובץ ה־HTML.
2. הפעל `RUN_STAGE22_GPU_BENCHMARK_WINDOWS.bat`. נדרש Python מותקן. אפשר לחלופין להשתמש בשרת HTTP מקומי אחר או לפרסם את כל הקבצים כאתר סטטי.
3. פתח ב־Chrome או Edge את `http://127.0.0.1:8765/START_GAME.html?stage22qa=1`.
4. הפעל את המשחק. באמצעות **F4** בחר **Native 1080p**, ועם **F3** אמת את הרזולוציה הפנימית. אם המסך ברזולוציה קטנה מ־1920×1080, בחר מסך מתאים ובטל זום/סקיילינג שאינו רצוי.
5. השאר את החלון **בקדמה**, עם האצת חומרה מופעלת. בכל אחת משש הסצנות בחר את שמה בחלונית, סמן שאתה נמצא בה, והתחל מדידה. **נוע בפועל** במהלך 3 שניות חימום ועוד 20 שניות מדידה. אל תשנה איכות במהלך המדידה.
6. חזור על התהליך בהליכה בעיר, נהיגה בצומת, נהיגה על גשר, טיסה במסוק, לובי, והליכה בחוף/נמל.
7. לחץ **ייצא דוח JSON** והעלה את הקובץ `SUNSET_STATE_STAGE22_REAL_1080P_GPU_BENCHMARK.json` לבדיקה. היעד מאושר רק אם `allSixScenesPassed=true` ואפשר לוודא שמדובר ב־GPU חומרתי.

## מה לבדוק בדוח

- `native1080Throughout=true` בכל סצנה, וגם `hardwareAdapterVerified=true` — רינדור תוכנה או מתאם לא מזוהה אינם הוכחת GPU.
- `averageFps >= 50` ו־`p95FrameMs <= 20` בכל סצנה. אם אחד המדדים נכשל, אין אישור.
- `validSceneThroughout=true` ו־`sceneSelectionConfirmedByUser=true`. מיקומי גשר, מסוק ונמל מאומתים ידנית בלבד.
- `gpuExecutionTimeMs=null`: הזמן המדווח אינו מדידת זמן של שאילתת GPU; הוא מדד לקצב ציור המשחק ולזמן CPU בלולאת הציור.
- צלם בנפרד את תצוגת F3 ואת מצב התאורה, הצללים, פנים המבנים והכבישים כשנדרש אימות חזותי.

## השוואה והשבתה

- `?stage22qa=1` — מפעיל מדידה אופציונלית.
- `?stage22qa=1&stage22BenchOff=1` — משבית מדידה לחלוטין, בלי שינוי באיכות המשחק.
- בלי פרמטר — המשחק נטען באופן רגיל, בלי עטיפת לולאת הציור.

**לא בוצעה בדיקת GPU במכונת יצירת החבילה:** אין התקן חומרה זמין וגם Chromium לא הצליח ליצור WebGL2. הנתונים הזמינים הם CPU ובדיקות ממשק בלבד.
