# SUNSET STATE — שלב 23 | בדיקת קריאות ציור על המחשב שלך

**מטרת הבדיקה:** למדוד את מספר הקריאות ל־WebGL2, נתוני ה־Instancing והיקף העלאת המידע לזיכרון הגרפי במהלך המשחק האמיתי. **זו אינה מדידת זמן GPU ואינה אישור 50FPS**.

1. חלץ את כל תיקיית המשחק מתוך ZIP, וודא ששמרת את `START_GAME.html` ואת תיקיית `assets` באותו מבנה.
2. ב־Windows הפעל `RUN_STAGE23_DRAW_PROFILE_WINDOWS.bat`. נדרש Python 3 לשרת HTTP מקומי. לחלופין, אפשר להפעיל שרת מקומי קיים.
3. פתח `http://127.0.0.1:8765/START_GAME.html?stage23qa=1` בדפדפן עם WebGL2 והאצת חומרה. במצב הרגיל (`START_GAME.html` ללא פרמטר) המדידה כבויה.
4. התחל משחק, בחר סצנת בדיקה, ובחלונית **שלב 23** לחץ `מדוד 12 שניות` בזמן משחק רגיל. תוכל למדוד בנפרד רחובות, עומס תחבורה, גשרים, לובי, חוף ובעלי חיים.
5. לחץ `ייצוא JSON`. מתקבל `SUNSET_STATE_STAGE23_WEBGL_DRAW_PROFILE.json`. הבדיקה מייצאת מספר קריאות ציור, קריאות Instancing, קריאות framebuffer מחוץ למסך, גודל נתונים שנשלחו ל־bufferData ו־bufferSubData, זמני tick ב־CPU ומועמדי גאומטריה גלויים.
6. לבדיקת A/B פתח `?stage23qa=1&stage23ProfilerOff=1`; לא תותקן שום עטיפת מדידה. יש להשוות **אותה סצנה ואותה תנועה**. אל תפעיל `?stage22qa=1` ו־`?stage23qa=1` יחד לצורך השוואת FPS: כלי שלב 23 מוסיף overhead מכוון למדידה.
7. עבור מדידת 50FPS עצמה, השתמש בנפרד בכלי שלב 22: `?stage22qa=1`, ב־Native 1080p, שש סצנות, 20 שניות מדידה לכל סצנה. אין להציג דוח שלב 23 כהוכחה ל־FPS.

## איך לקרוא את הנתונים

- `drawCallsPerFrame`: מספר קריאות draw* שנמדדו בפועל בזמן הפעלת המכשור. **לא** מספר חלקי הגאומטריה.
- `trianglesSubmittedEstimatePerFrame`: משולשים שנשלחו, כולל Instancing וציור חוזר ב־shadow/offscreen; אין כאן מדידת משולשים גלויים בפיקסלים.
- `uploadBytesPerFrame`: כמות הבתים שהועברה בקריאות `bufferData` במהלך פריימי המדידה. **לא** נפח VRAM בשימוש (ולא כולל בהכרח טקסטורות).
- `staticVisible`: אובייקטים שהמנוע בחר למאגר התצוגה; אינם בהכרח Draw Calls.
- `cpuTickMsPerFrame`: זמן CPU של פונקציית tick, כולל overhead של כלי המדידה. אינו זמן GPU.
- `gpuExecutionTimeMs` ו־`gpuResidentMemoryBytes` נשארים `null` במכוון.

## מה נשאר פתוח

אין בסביבת הבנייה התקן GPU פיזי או WebGL2 פעיל. דוח CPU מבוסס על העולם האמיתי עם renderer מדומה; בדיקת Chromium היא **בדיקת ממשק עם WebGL מדומה**. יש להשיג דוח שלב 23 מהמחשב שלך כדי לקבוע עומס Draw Calls והעלאות אמיתי ולהצליב עם מדידות שלב 22. שיפור איכותי ומדידת 50FPS נדרשים בהמשך.
