# Recovery 7: device-side visual QA checklist

Run `START_GAME.html?recovery7qa=1` after extracting the full project. Start the game first. Use the live checklist panel to mark each scene and export `SUNSET_RECOVERY07_LIVE_QA.json`.

1. Downtown: WASD movement, diagonals, sprint, jump, walls and slopes.
2. Traffic: regular and fast driving, braking, collisions and vehicle exits.
3. Bridge: drive up/down ramps; verify traffic below is unaffected and vehicles do not hang over curved barriers.
4. Store and lobby: walk across thresholds and inspect actual interior continuity.
5. Lift/stairs: travel between floors, use buttons, and leave the building by its normal exit.
6. Crocodile from 150m, 70m, 30m, 5m: evaluate geometry switching and head proportions; inspect herons, flamingos and fish by water.
7. Clock: should begin 12:15 with the cycle paused, then start/stop when toggled; evaluate sunny weather, night, rain.
8. NPCs: conversations, crosswalks, responses to fast vehicles and events; test mission and police interactions.

For each scene use the 20-second display-frame measurement; assess its actual buffer resolution and sustained FPS. F3/F10 are also available. Frame cadence is not direct GPU timing. The canvas PNG capture button might produce blank images in certain WebGL browsers; use the system screenshot shortcut if that happens.

Record any defect with exact location, scenario, date, observed behavior, expected behavior and screen capture. No screenshot was generated by the automatic project audit because the testing browser blocked all navigations with ERR_BLOCKED_BY_ADMINISTRATOR.
