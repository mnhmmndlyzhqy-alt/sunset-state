# שלב 24 — בדיקות GPU ופרסום שעדיין נדרשות

בדיקות שלמות הקבצים ובדיקות יחידה **אינן** מחליפות הרצה של המשחק על כרטיס מסך אמיתי.

1. חלץ את כל קובצי ה־ZIP. פתח את `START_GAME.html` דרך שרת HTTP מקומי במידת הצורך.
2. הפעל את `RUN_STAGE22_GPU_BENCHMARK_WINDOWS.bat`, בחר רזולוציית רינדור פנימית של **1920×1080**, והריץ את שש סצנות הבדיקה. שמור דוח JSON עם נתוני GPU, זמני פריימים, FPS ורזולוציה. אל תחשיב רינדור תוכנה כהצלחת GPU.
3. בנפרד, הפעל את `RUN_STAGE23_DRAW_PROFILE_WINDOWS.bat` ושמור פרופיל קריאות ציור, Instancing והעלאות buffers. אין להפעיל אותו יחד עם מדידת FPS, משום שכלי הפרופיל עצמו מוסיף עומס.
4. בדוק ידנית כבישים, גשרים, חנויות, מעליות, רכבים, משטרה, בעלי חיים, שמירה וטעינה. צרף צילומי מסך אמיתיים מהמשחק.
5. רק לאחר מעבר בדיקות פרסום, בדוק אפשרות לפרסם ב־GitHub Pages או שירות אירוח מתאים. **לא בוצע פרסום בשלב 24**.
6. בשלב 26 יש לבחון את 25 הממצאים המקוריים מול ראיות משחק אמיתיות, ולא לסגור אותם רק על בסיס סימולציות CPU.

ממצאים שלא עברו חייבים להישאר פתוחים. יעד לפחות 50FPS ב־Full HD **לא הוכח בסביבה הנוכחית**.
