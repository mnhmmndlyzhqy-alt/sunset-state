# SUNSET STATE — שלב 30 מתוך 35: שחקן ודמויות NPC

**הבסיס:** כל 1,004 קובצי שלב 29 נשמרו, עם גיבוי לגרסאות המקור של הקבצים ששונו. הפרויקט אינו משחק חדש.

## שיפורים

- שיפור הנראות של פני השחקן, במיוחד מיקום העיניים והאף, בלי להחליף את מודל ה-AeroWild המקורי.
- התאמת נשימה, רגל/נעל, פנים וצווארון לשחקן. כיפה וציצית נשמרו.
- ליטוש תנועת NPC ופרטי לבוש/פנים רק מטווח קרוב כדי להגביל עומס.
- 20 מודלי Urban GLB המקוריים וריגי Street Character V8 נשארים ללא שינוי בקובצי הנכסים; הבעות GLB ממשיכות דרך expression443.
- כיבוי זמני לשם השוואה: `?stage30CharactersOff=1`.

## בדיקות ומגבלות
